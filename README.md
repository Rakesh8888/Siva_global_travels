# Siva Global Travels — Website Prototype

Mobile-first single-page website for Siva Global Travels.

## Included
- Responsive homepage and navigation
- Flight enquiry form with one-way/round-trip, airport options, passenger count, cabin class, and dates limited to today through three months ahead
- Flight enquiry is sent to WhatsApp; it does **not** show invented live prices
- Travel, visa, tour, overseas job and cruise job service sections
- WhatsApp contact form
- LUCKY AI demo assistant with preset replies
- English/Telugu toggle for main hero text and light/dark theme toggle

## Run
Open `index.html` in a browser, or import this folder into Bolt.new.

## Before public launch
- Verify the WhatsApp business number and contact details.
- Connect a real flight API through a secure server-side backend before advertising live fares or booking.
- Connect a real AI API securely if LUCKY AI should use a live model.
- Add privacy policy, terms, business identity and any required licenses.
- This prototype does not sell tickets, process payments, or submit enquiries to a server; it opens WhatsApp with a prefilled message.
